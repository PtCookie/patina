Where shipping the full text is impractical NAVER recommends a credit line instead ("이 페이지에는 네이버에서 제공한 마루 부리 글꼴이 적용되어 있습니다."). NAVER may use images of print or ads set in its fonts for promotion; you can ask NAVER to opt out.

Never subset, convert (OFL counts a format change as a modification) or otherwise modify a font with a Reserved Font Name — Pretendard, D2Coding, MaruBuri — and keep the name — use the official builds as they are, or rename the derivative.
