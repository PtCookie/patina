# Article

A long-form reading page — blog posts, docs, release notes: `heading` titles over `serif` reading text.

**Consumer provides:** an eyebrow line (`caption` in `sans`, `muted-foreground`), a title, section headings, paragraphs, and optional quotes and inline code.

- Title `heading-2xl` (JetBrains Mono → Pretendard, 30/36 semibold); `h2` `heading-xl`, `h3` `heading-lg`; all headings `text-wrap: balance`.
- Body `serif-body` (Newsreader → MaruBuri) 17/28 with a 640px measure; quotes `serif-quote` with a 2px `border` rule on the left, in `muted-foreground`.
- Inline code stays `mono` on `muted` with `radius-sm`.
- `serif` is for reading text only — never titles, buttons, menus, tables or any UI chrome.
