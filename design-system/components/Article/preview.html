Notes on rebasing 리베이스에 관하여

A branch is a movable pointer to a commit. git rebase replays your commits on top of another base, so the history reads as if you had started there.

브랜치는 커밋을 가리키는 움직이는 포인터입니다. 리베이스는 내 커밋을 다른 기준점 위에 다시 쌓아서, 처음부터 거기서 시작한 것처럼 기록을 정리합니다.

Rebase vs merge 리베이스와 병합

Merging keeps every branch point; rebasing rewrites them into a straight line.

Make it work, make it right, make it fast.
