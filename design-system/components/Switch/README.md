# Switch

A 44×20 pill (`radius-full`, 2px inset border) with a 24×16 pill thumb; on = `primary`, off = `input` at 90%.

**Consumer provides:** a label, the state, and an immediate effect — a switch never waits for a Save button.

- Thumb is `background` in light; in dark it is `foreground` when off and `primary-foreground` when on.
- `sm` size: 28×16 track, 16×12 thumb.
