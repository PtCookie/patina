# Separator

A 1px `border` hairline, horizontal (full width) or vertical (full height of its row).

**Consumer provides:** the orientation, and `decorative` when it only groups visually (screen readers then skip it).

- Use it to divide groups inside one surface (a card, a menu, a footer row). Between whole sections, use spacing (`space-8`) instead.
- Never thicker than 1px and never a color other than `border`.
