# Kbd

A keycap for shortcuts: 22px tall, min-width 22px, `radius-sm`, `muted` fill, `caption` text in `muted-foreground`, set in Inter (not mono).

**Consumer provides:** one key per Kbd; group several with `space-1` gaps. Inside an input group tint it `muted-foreground` at 10%; inside a tooltip invert it to `background`.
