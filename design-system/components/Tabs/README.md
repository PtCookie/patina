# Tabs

A `muted` pill track (36px, padding `space-1`, `radius-full`) holding pill triggers; the active trigger lifts onto `background`.

**Consumer provides:** 2–5 short labels (optionally a leading icon) and the panels they switch.

- Triggers: `label` style, padding `space-1` × `space-3`, inactive text `foreground` at 60%, hover full `foreground`.
- Active: `background` fill with a hairline shadow (dark: `input` at 30%).
- Vertical tabs use `radius-2xl` for the track and `radius` for triggers instead of pills.
