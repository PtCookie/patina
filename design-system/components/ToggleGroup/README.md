# ToggleGroup

Joined outline Toggles for one choice (or several) out of a short set — chart periods, list vs grid.

**Consumer provides:** 2–5 items with short labels or icons (`aria-label` on icon-only items), `type` single or multiple, the selected value(s).

- Items share hairlines (no gap); the group's outer corners take `radius`, inner corners are square. The selected item fills `muted`.
- Single-select groups always keep one item on. More than five choices → Select.
